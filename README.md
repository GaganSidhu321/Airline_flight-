# Airline Flight Data Analysis

## 📌 Overview
A data analytics project focused on airline and flight data to explore patterns, trends, and useful operational insights.

## 🧰 Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔎 Workflow
1. Load the flight dataset
2. Inspect data quality
3. Clean missing and incorrect values
4. Perform Exploratory Data Analysis (EDA)
5. Visualize important patterns
6. Summarize analytical findings

## 📊 Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Python Data Manipulation
- Business Analytics
